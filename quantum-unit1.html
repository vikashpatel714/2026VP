01

Classical vs. Quantum Algorithms

A classical algorithm is a fixed recipe of deterministic (or randomized) steps run on bits that are always either 0 or 1. A quantum algorithm runs on qubits that can be 0, 1, or a weighted combination of both at the same time — and it uses that combination, plus interference, to make right answers more likely and wrong answers cancel out.

Classical computingQuantum computing
Basic unitBit — exactly 0 or 1Qubit — a superposition α|0⟩ + β|1⟩
State of n unitsOne of 2ⁿ values at a timeA weighted blend of all 2ⁿ values at once
OperationsLogic gates: AND, OR, NOTUnitary (reversible) gates: X, H, CNOT…
Reading the answerAlways reveals the exact value storedMeasurement collapses to one outcome, with a probability
Copying dataFreely copyableForbidden for unknown states (no-cloning theorem)
Searching N itemsO(N) — check one at a timeO(√N) — Grover's algorithm
Factoring large numbersExponential time — practically infeasiblePolynomial time — Shor's algorithm

Real-life picture

Imagine a warehouse of 1,000,000 sealed boxes and exactly one holds a prize. A classical worker opens boxes one by one — worst case, all 1,000,000 checks. A "quantum worker" can, in a sense, examine all boxes in one coordinated sweep, then use interference to make the sweep echo louder near the prize and quieter everywhere else, needing only about 1,000 sweeps (√N) to be confident.

KEY IDEA

Quantum computers are not "faster classical computers" — they don't try every possibility and pick the best like brute force. They shape probability amplitudes so that constructive interference lands on correct answers and destructive interference cancels wrong ones. Speed-up comes from clever interference, not from raw parallel brute force.

Quantum Parallelism & Amplitude Amplification

Put n qubits into an equal superposition of all 2ⁿ inputs, apply a function f as one quantum circuit, and — in a single pass — the register now encodes f(x) for every x simultaneously. This is quantum parallelism. The catch: measuring immediately gives back only one random x, so the trick only pays off once we boost the amplitude of the answer we actually want — that boosting step is amplitude amplification.

Step 1 — Create superposition

Starting from n qubits at |0...0⟩, apply a Hadamard gate to each:

H⊗n |0⟩⊗n  =  (1/√2ⁿ) Σx=0…2ⁿ-1 |x⟩

Every one of the 2ⁿ basis states now carries the same small amplitude 1/√2ⁿ.

Step 2 — Query the oracle

A quantum oracle Uf flips the sign (phase) of amplitudes belonging to "marked" (correct) states, leaving their size the same but pointing the opposite way. Nothing looks different yet if you measure now — the sizes (probabilities) are still equal.

Step 3 — Amplify

A reflection about the average amplitude (the "diffusion" step) turns that sign flip into a real size increase: marked amplitudes grow, unmarked amplitudes shrink. Repeating steps 2–3 about (π/4)√N times pushes the probability of measuring the correct answer close to 1.

Numerical example — 2 qubits, 1 marked item

N = 4 items, one target (say |10⟩). Watch the amplitudes evolve:

One Grover iteration on N = 4 with one marked item already reaches ~100% — in general it takes ⌊(π/4)√N⌋ iterations.

REAL-LIFE ANALOGY

Think of noise-cancelling headphones: every sound wave (amplitude) is present, but the circuit shifts the phase of unwanted noise so it destructively cancels, while the wave you want to hear survives. Amplitude amplification does the same thing to probabilities instead of sound.

03

Quantum Circuit Model & Gates

A quantum circuit is read left to right: horizontal lines are qubits, boxes are gates (unitary, reversible operations), and a meter symbol is a measurement that turns a qubit back into a classical bit. Time flows left → right; each vertical slice can act on several qubits at once.

q₀ starts in |0⟩, gets a Hadamard, then controls a NOT on q₁ (CNOT) — this entangles them into a Bell pair, which is then measured.

Worked numerically, this is the standard recipe for building the entangled Bell state — tracked here as a 4-number vector over the basis (|00⟩, |01⟩, |10⟩, |11⟩):

Stage|00⟩|01⟩|10⟩|11⟩
Initial: |00⟩1.0000.0000.0000.000
After H on q₀0.7070.0000.7070.000
After CNOT(q₀→q₁)0.7070.0000.0000.707

The final state 0.707|00⟩ + 0.707|11⟩ is a Bell state: measuring q₀ and q₁ always gives matching results (00 or 11), each with 50% probability — even though before measurement neither qubit had a definite value on its own.

REAL-LIFE ANALOGY

Read a quantum circuit the way you'd read sheet music: each qubit line is a stave, each gate is a note played at a precise moment, and time moves left to right. Because every gate is reversible, you could hand the finished "score" to someone and they could play it backwards, note for note, and land exactly back on silence — something an ordinary (classical) recipe, where steps like cracking an egg can't be undone, never allows.

Qubit

A 2-level quantum system. Its state |ψ⟩ = α|0⟩ + β|1⟩ with |α|² + |β|² = 1. |α|² and |β|² are the probabilities of measuring 0 or 1.

Unitary gates

Every gate U must satisfy U†U = I — this makes quantum computation reversible: you can always run a gate "backwards" to undo it.

Measurement

The only non-reversible step. It converts amplitudes into one classical outcome, sampled according to |amplitude|².

Entanglement & the No-Cloning Theorem

The Bell state built above is entangled: the two qubits share one joint description that cannot be split into "qubit 0's state" times "qubit 1's state." Measuring one instantly tells you the other's outcome, no matter how far apart they are.

q₀ = ?
q₁ = ?

Numerical view of the Bell pair

State: 0.707|00⟩ + 0.707|11⟩. There is no way to write this as (α|0⟩+β|1⟩) ⊗ (γ|0⟩+δ|1⟩) for any single-qubit numbers — try multiplying it out and you'll always pick up an |01⟩ or |10⟩ term that shouldn't be there. That algebraic fact is entanglement.

Measure q₀: 50% chance of getting 0 (and the state instantly becomes |00⟩, so q₁ must read 0 too), 50% chance of getting 1 (state becomes |11⟩, q₁ must read 1 too).

No-cloning theorem

There is no quantum gate that copies an arbitrary unknown qubit state — i.e. no unitary U with U(|ψ⟩|0⟩) = |ψ⟩|ψ⟩ for every |ψ⟩. This is why quantum information has to be transmitted or teleported rather than duplicated, and it's the reason quantum cryptography can detect eavesdropping.

REAL-LIFE ANALOGY

Take a pair of gloves, put each one in a separate sealed box, and mail the boxes to opposite sides of the world without looking inside. The moment someone opens one box and sees "left," they instantly know the other box holds "right" — no signal had to travel between them. Quantum entanglement is the genuinely stranger cousin of this idea: unlike the gloves, the qubits don't have a fixed value until the moment they're measured.

CNOT (2-qubit gate)

Flips the target qubit only when the control qubit is |1⟩. It's the standard way to entangle two qubits.

|00⟩→|00⟩
|01⟩→|01⟩
|10⟩→|11⟩
|11⟩→|10⟩

Why gates must be reversible

Because U†U = I, every gate has a unique inverse (X undoes X, S† undoes S). This is why quantum circuits never "erase" information the way a classical AND gate does — it's a strict requirement of quantum mechanics.

Gate ↔ everyday action

  • XFlipping a light switch — on becomes off, off becomes on.
  • ZTurning a coin over without moving it — heads still looks like heads, but "which side is up" flips.
  • HStirring two paint colors into an even 50/50 blend — pure |0⟩ becomes an equal mix of |0⟩ and |1⟩.
  • S/TRotating a steering wheel by one precise, small click — the direction shifts a little without changing speed.
  • CNOTTwo dancers where the second only spins if the first is currently facing a certain way.

Deutsch's Algorithm

Problem: you're given a hidden function f:{0,1}→{0,1} as a black-box oracle. It is either constant (f(0)=f(1)) or balanced (f(0)≠f(1)). Classically you must call f twice in the worst case. Deutsch's algorithm decides it with one quantum call.

Top qubit starts |0⟩, bottom (ancilla) starts |1⟩ — both get a Hadamard, pass through the oracle U_f, top qubit gets a final Hadamard, then is measured.
1
Initialize. |ψ₀⟩ = |0⟩|1⟩ state = |01⟩
2
Hadamard both qubits — creates superposition on the query qubit and the |−⟩ = (|0⟩−|1⟩)/√2 "phase kick-back" ancilla. |ψ₁⟩ = ½(|0⟩+|1⟩)(|0⟩−|1⟩)
3
Apply U_f. The oracle writes f(x) into the ancilla's phase via kick-back: |ψ₂⟩ = ½Σₓ(−1)^f(x)|x⟩(|0⟩−|1⟩)
4
Hadamard the top qubit again. Interference now separates the two cases perfectly.
5
Measure the top qubit. Result 0 → f is constant, result 1 → f is balanced — with 100% certainty, from a single oracle call.
REAL-LIFE ANALOGY

Imagine tasting two cups of tea to check if they're identical or different, but you're only allowed one sip total. Deutsch's trick is like mixing both cups into one glass in a special way so that a single sip's aftertaste alone tells you "same" or "different" — no need to taste each cup separately.

08

Deutsch–Jozsa Algorithm

The generalization to n input bits: f:{0,1}ⁿ→{0,1} is promised to be either constant (same output for all 2ⁿ inputs) or balanced (output is 0 for exactly half the inputs, 1 for the other half). Classically, a deterministic algorithm may need up to 2ⁿ⁻¹ + 1 calls to be sure. Quantumly, it always takes exactly one call.

How it generalizes Deutsch

Same three-part shape: Hadamard all n query qubits + the ancilla, one oracle call, Hadamard the n query qubits again, then measure them all.

measure all-zero string |0⟩⊗n ⇒ f is constant
measure anything else ⇒ f is balanced

The all-zeros outcome only has full amplitude when every phase kicked back by the oracle points the same way — which happens exactly when f never changes value.

Worked example, n = 2, with a balanced f (f(00)=0, f(01)=1, f(10)=1, f(11)=0): after Hadamarding both query qubits and applying U_f, the amplitude on each basis state carries a sign (−1)^f(x):

x00011011
f(x)0110
amplitude on |x⟩ (×½)+0.500−0.500−0.500+0.500

After the final Hadamards, these mixed signs interfere destructively on |00⟩ — its amplitude comes out to exactly 0, so |00⟩ is never measured, correctly flagging f as balanced. For a constant f every sign would be the same, and |00⟩ would be measured with probability 1.

n query qubits + 1 ancilla, one call to U_f, then measure only the n query qubits.
REAL-LIFE ANALOGY

Suppose 1,000 friends each secretly voted yes/no, and you're told the vote was either unanimous or exactly 500–500. Classically you might have to ask 501 people before being sure. Deutsch–Jozsa is like a single cleverly designed group photo whose shadow pattern instantly reveals "unanimous" vs "split" without polling anyone individually.
